# 学习指南

[返回项目首页](../README.md) · [开发指南](development.md)

## 从一个知识点开始

先阅读原理与对比示例，再进入「亲手试一试」。你可以修改示例并运行，观察不同写法如何影响结果；深入讲解用于补充当前知识点。

每章小试卷有 8 道题，包含选择、填空和编程题。每题独立提交并即时反馈；单题失败至少 3 次后，才可以主动查看答案和解析。本章题目全部通过后解锁专项项目。

编程题通过注入断言实际运行检查。判题面向自学，不提供防作弊保证。

## 使用代码实验室

编辑器通过文件标签切换 `main.rs` 与 `Cargo.toml`。TOML 支持语法高亮，依赖通过行尾勾选框管理，可选范围为课程预设的常用 crate。

编辑器和终端可以上下或左右排列，并支持拖拽分隔线和网页全屏。页头的折叠菜单按钮可以收起侧栏，网页全屏可按 Esc 退出。

工具栏可以隐藏或显示 Rust 注释，并记住偏好。独立注释行会从视图折叠，行尾注释会隐藏；原始源码、行号、编译输入和草稿不受影响，字符串中的 `//` 也不会被隐藏。

终端支持 ANSI 颜色，按进程输出到达的顺序增量显示。程序自身的输出缓冲仍需通过换行或 flush 控制。

## 记录笔记与注释

章节笔记位于课时页尾，本章各节共用，支持 Markdown。直接在页尾新增或修改，点击「保存笔记」或「取消」。旧版本的课时笔记会在升级时按章节汇总。

选中教材文字可以添加 Markdown 注释。标记文字会高亮，点击摘要胶囊即可展开全文；只有新增或修改时才进入编辑框。

右下角「本章注释」可以展开列表，点击条目跨课时定位原文。定位使用引文、上下文和原始偏移，刷新后会恢复。若原文已删除，注释仍保留在列表中并可修改。

## 保存与迁移学习记录

无需账号。当前站点的 localStorage 保存草稿、答案、失败次数、进度、笔记、注释、输出、依赖、布局、分隔比例和专注状态。

不同浏览器、不同端口的记录不会自动共享。清理站点数据会删除本地记录。通过「学习足迹」导出 JSON 可以备份，导入会替换当前记录，笔记和注释一并迁移。

课程重组会保留已有知识点 ID、草稿、笔记，以及未改写题目的通过记录。已换题的旧成绩存入 `archivedPassed`，不会自动视作新题通过。

## 运行模式

| 能力                           | 本机增强模式                                 | 浏览器模式                     |
| ------------------------------ | -------------------------------------------- | ------------------------------ |
| 代码执行                       | 本机 Cargo，支持 run / check / build / test  | WASM Miri，适合基础语法实验    |
| 编辑提示                       | 本机 rust-analyzer，提供补全、悬浮说明与诊断 | 历史实验版分析器，语义支持有限 |
| 外部 crate、原生线程、系统网络 | 支持课程中的本机示例                         | 不支持                         |
| 完整 Cargo 工程                | 受课程实验室的编辑范围限制                   | 不支持                         |

语言服务启动失败时也会尝试浏览器基础语义回退。浏览器回退不保证最新 Rust 语法和语义分析完整，不能替代本机工具链。

网页默认使用浏览器模式，不会自动连接本机服务。想使用本机 Cargo 和完整语言服务时，按下方步骤连接；选择「浏览器模式」即可关闭连接。

浏览器运行资源首次加载较大，会通过 Cache Storage 缓存；项目不承诺完整离线 PWA。

## 连接本机语言服务

本机增强服务使用 Rust 编写，可独立启动，无需安装 Node.js。它调用你电脑上的 Cargo 和 rust-analyzer，为网页编辑器提供以下能力：

- **代码补全**：输入变量、类型或方法时提供候选项，包括已选择的课程依赖。
- **悬浮说明**：将鼠标放在符号上查看类型、函数签名和文档。
- **实时诊断**：编辑后显示语法、类型和借用等编译问题，不必每次手动点击运行。
- **Cargo 执行**：运行、检查、构建或测试当前代码，支持课程预设的外部依赖。

### 第一次连接

1. 通过 rustup 安装 Rust stable，并执行 `rustup component add rust-analyzer rust-src`。确保 `rustc`、`cargo` 和 `rust-analyzer` 可在终端运行。
2. 前往[发布页](https://github.com/YanChenBai/rust-path/releases)下载适合当前系统的增强服务。Windows 用户启动 `rust-path-server.exe`，通过 `--origin` 允许当前学习网页的来源。例如网页地址为 `http://localhost:5173`：

   ```powershell
   .\rust-path-server.exe --origin http://localhost:5173
   ```

3. 保持服务进程运行。点击网页页头的插头按钮，在「Rust Service」中填写 `http://127.0.0.1:3000`，点击「保存并连接」。地址只保存在当前浏览器。
4. 等待 `Rust Analyzer` 的索引进度结束，再使用完整补全和悬浮说明。

网页来源需要与地址栏中的协议、主机和端口一致；`localhost` 与 `127.0.0.1`、不同端口都算不同来源。设置卡片的「如何连接独立服务」会给出当前网页对应的启动命令。增强服务可直接从发布页下载，无需自行构建；从源码构建的方法见[开发指南](development.md#独立本机服务与-windows-exe)。

### 看懂连接与加载状态

插头旁的灰点表示浏览器模式或尚未连接，黄点表示连接中，绿点表示服务已连接，红点表示连接失败。绿点只说明增强服务可访问，语言服务还可能正在读取项目和建立索引。

页头的圆圈分别显示 `Rust Engine`（运行能力）、`Code Tools`（编辑器资源）和 `Rust Analyzer`（本机语言服务）的加载状态。语言服务会显示获取项目信息、扫描源码、索引等当前阶段；提供百分比时显示真实进度，其余阶段显示转圈。完成后指示会自动淡出，快速完成的任务不会闪现。

首次索引标准库、首次下载依赖或切换所选依赖时可能需要更久。等待期间可以继续阅读和编辑；完整语言提示需等索引完成。若显示加载失败，可根据提示检查工具链或重新连接。

### 无法连接时

- 先访问服务地址，正常情况下会显示状态 JSON；`/api/capabilities` 可查看工具链能力。这个地址提供增强接口，课程页面仍从原来的网页地址打开。
- 如果连接被拒绝，确认服务终端仍在运行，端口与网页填写的地址一致；启动时可用 `--port 3001` 更换端口。
- 如果直接访问正常、网页连接失败，检查 `--origin` 是否与当前网页来源一致，以及浏览器是否允许网页访问本地网络。
- 若启动检查提示缺少组件，执行 `rustup component add rust-analyzer rust-src` 后重启服务；也可执行 `.\rust-path-server.exe --check` 单独检查工具链。

## 当前课程边界

实验室以单个 `main.rs` 与受控 `Cargo.toml` 为运行单元。模块示例可以通过内联模块真实运行；Workspace 的多文件结构在教材中讲解，暂不提供任意文件树和多 crate 项目的编辑执行。

HTTP 协议示例是有限的本机实验，不能代替生产服务框架。Unsafe / FFI、过程宏编写、性能分析与 WebAssembly 属于后续选修方向，尚未列入当前 32 章。

资料以当前 Rust Book、Rust by Example、标准库与依赖官方文档为准。[中文旧译本](https://rustwiki.org/zh-CN/book/)仅参考讲解组织，不以其 Rust 1.58 作为语义标准。原生示例采用 Edition 2024，编译器版本取决于本机工具链。
