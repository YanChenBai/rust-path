### 4. 数值契约与接口粒度

函数参数类型限制了表示范围，却不自动保证业务范围。`u32` 排除了负数，但没有排除每天超过一千分钟这样的输入，也没有防止乘法溢出。本例只使用小数值展示调用；面向外部输入时，应在边界验证范围或返回 `Result`。将验证和核心计算的责任写清楚，比每层都猜测调用者是否已经检查过更容易维护。
<CourseCallout title="容易混淆的地方">

`fn` reward() -&gt; `u32` { 50; } 丢弃了整数并得到 ()。另外，打印计算结果不等于返回该结果，调用方需要复用数值时应真正返回它。

</CourseCallout>
