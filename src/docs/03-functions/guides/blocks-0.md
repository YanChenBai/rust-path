### 1. 代码块拥有局部名称，也能产生结果

块表达式既建立局部作用域，也可以通过尾表达式产生值。外层只保留计算结果，临时变量隐藏在块内，能减少后续代码误用中间状态的机会。作用域描述名称可以在哪些位置被解析，并不是程序实际执行了多久；一个内部声明可能每次循环都重新创建，也可能因为所在分支从未执行而完全不创建。

块中最后一个没有分号的表达式决定正常结束时的值；若最后是带分号的语句，通常返回 ()。花括号本身不会自动复制数据。块可以返回整数，也可以把内部创建的 `String` 移到外部，接收方成为新所有者。判断是否安全应看值或引用的来源，而不只是看它写在哪一对花括号里面。
