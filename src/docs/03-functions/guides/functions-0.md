### 1. 函数签名描述调用双方的责任

参数必须声明类型，返回类型放在箭头之后；这让函数体内部与外部调用可以分别检查。`fn length(text: &str) -> usize` 表示只借用文本并返回长度，`fn consume(text: String)` 则表示接收所有权。两者可能读取相同内容，但调用之后原变量是否还能使用完全不同，签名本身就是资源使用协议。

函数调用会先求值参数表达式，再进入函数体。普通函数不能直接捕获调用者的局部变量，所需数据应通过参数传入；需要捕获环境时可以使用闭包。把计算写成显式输入、显式输出的小函数，既便于推理，也让测试不必依赖终端输入或共享状态。函数定义位置不要求早于调用位置。
