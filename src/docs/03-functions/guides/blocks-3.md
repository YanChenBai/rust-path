### 4. 借用结束与析构发生不要混淆

NLL 可以让一次借用在最后一次使用后结束，但拥有资源的局部变量通常仍在其析构作用域结束时才释放。需要明确缩短文件、锁守卫等资源的持有时间时，可使用内层块或显式 drop，而不是仅仅停止读取变量。Rust 2024 还调整了部分临时值的作用域；初学时应优先显式绑定和清晰分块，不依赖复杂尾表达式中的临时析构顺序。
<CourseCallout title="容易混淆的地方">

不要把“块内变量不能在外部访问”误解成“块内产生的数据都不能返回”。返回所有权与返回借用是两种不同情况。

</CourseCallout>
