### 4. 用相邻输入检查边界

阈值逻辑至少要观察边界前一项、边界本身与后一项，例如五十九、六十、六十一分钟。如果有多个区间，还要检查区间之间是否遗漏或重叠。示例中的大于等于让六十恰好归入一小时档；改成大于会改变这个业务约定。对于有限状态，`match` 往往比一串布尔条件更容易表达完整性；对于大小比较，`if` 通常更直接。
<CourseCallout title="容易混淆的地方">

不要为解决分支类型错误而随意把所有值转成字符串。先决定结果究竟是数值、文字还是某个枚举，再统一各条执行路径。

</CourseCallout>
