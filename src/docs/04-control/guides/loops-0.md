### 1. 范围的右端点决定遍历次数

a..b 包含左端点而排除右端点，a..=b 两端都包含。零到长度的半开范围正好对应合法下标，但零到等于长度会多走一次并越界。对于整数，3..3 不产生元素，3..=3 则产生一次。不要为了包含最大值机械地把上界加一，最大整数加一可能溢出；能表达业务时直接用包含式范围。

`for` 从迭代器逐个取值，通常比手动维护下标和停止条件更适合遍历集合。只关心元素时写 `for` value in &values；既关心位置又关心元素时使用 enumerate。这样不会把“当前下标”与“已处理数量”混用，也减少了每次修改集合长度后重新检查边界的负担。
