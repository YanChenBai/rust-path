### 1. 模式描述形状，穷尽检查保证覆盖

`match` 先求出待匹配表达式，再按分支顺序寻找匹配模式，执行选中的分支。模式不是任意布尔表达式，它描述值的结构，例如 `Some(value)`、元组或包含端点的数值范围。编译器要求覆盖所有可能输入；匹配枚举时漏掉一个变体会报错，因此新增业务状态能主动暴露需要更新的处理位置。

通配模式 _ 匹配剩余情况但不建立名称绑定。普通标识符却会绑定匹配到的值，并不是拿它与某个同名局部变量比较。若要比较运行时阈值，应写守卫，例如 `value if value >= limit`。守卫是附加条件，编译器通常不会靠它证明整个类型已被覆盖，仍然需要一个无守卫的兜底分支。
