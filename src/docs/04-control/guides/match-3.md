### 4. Rust 2024 下避免冗余引用模式

在 Rust 2024 中，当匹配外层引用已经让内部默认按引用绑定时，不能再随意添加 ref、ref `mut` 或 `mut` 来改变绑定方式。示例直接写 `Some`(text) 就能得到共享引用，不必照搬旧教程的 `Some`(ref text)。需要修改时先决定是匹配 &`mut` 数据还是拿走所有权，再观察内部绑定类型。优先保持模式简单，可避免在多层引用中意外解引用或移动数据。
<CourseCallout title="容易混淆的地方">

不要靠最后一个 _ 掩盖每个枚举的新变体。如果每种状态都有独立业务含义，显式列出变体更利于未来修改时获得编译器提醒。

</CourseCallout>
