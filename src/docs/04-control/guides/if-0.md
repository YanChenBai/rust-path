### 1. 条件只能是 bool，判断顺序有意义

`if` 根据布尔条件选择执行路径，Rust 不会把零、空字符串或空集合自动当成假。要判断是否有记录，应写 !records.is_empty()，而不是直接写 records。`else` `if` 从上向下检查，一旦某个条件成立，就不再执行后续条件和分支。因此先判断六十分再判断九十分，会让高分始终进入前面的及格分支。

&& 与 || 采用短路求值：左侧已经决定结果时，右侧不会执行。这既能节省工作，也能保护有前提的操作，例如先确认除数非零再做除法。不要把必须发生的更新或日志隐藏在可能被短路跳过的右侧表达式中；需要总是执行的动作应单独安排，并明确其发生时机。
