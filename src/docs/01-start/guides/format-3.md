### 4. 注释说明约束，文档注释说明接口

// 注释持续到本行末尾，块注释使用斜杠星号配对，二者都不参与程序计算。函数前的 /// 文档注释可被 rustdoc 收集，并能包含可检查的示例。普通注释适合解释为什么按字节计数、为什么排除右端点等约束，而不是重复“这里加一”。当代码行为改变时，过时注释同样会误导读者，应与实现一起更新。
<CourseCallout title="容易混淆的地方">

`Vec` 默认没有 `Display`，直接用 {} 打印会编译失败；调试观察可用 {:?}。格式字符串来自用户时，可用 `println!("{}", text)` 原样输出。

</CourseCallout>
