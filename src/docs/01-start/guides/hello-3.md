### 4. 先判断错误发生在哪一层

缺少引号、括号或函数名属于编译期问题，此时还没有执行本次修改后的程序。能够启动却输出错误结果属于逻辑问题，运行时触发 panic 则是另一类失败。排查时先看第一条有意义的诊断及其源码位置，不要把终端中上次运行留下的输出当作本次编译的结果。这个区分在学习所有权报错和数组越界时尤其重要。
<CourseCallout title="容易混淆的地方">

字符串使用英文双引号，宏名后的 ! 不能遗漏。修改源码后必须重新编译，旧可执行文件不会自动更新。

</CourseCallout>
