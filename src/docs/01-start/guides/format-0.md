### 1. 格式字符串是一份编译期契约

`println!` 的第一个参数通常必须是格式字符串字面量，编译器据此检查占位符、参数和格式化能力。{} 使用 `Display`，适合面向使用者的文字；{:?} 使用 `Debug`，适合查看数组、元组和派生调试输出。`Debug` 不是稳定的数据交换格式，不应把它当作可以长期存储并重新解析的协议。

既可以按位置传参，也可以用 {name} 捕获当前作用域已有的变量。这里的花括号不是任意表达式求值器：要输出计算结果，应写 `println!`("{}", minutes * 2)，而不是把乘法直接塞进捕获名称。输出字面花括号时使用 &#123;&#123; 与 }}，它们不会消耗额外参数。
