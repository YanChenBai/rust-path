### 1. 源码如何成为可执行程序

Rust 源码不是逐行交给解释器执行的脚本。编译器先解析语法，检查名称、类型和借用关系，再生成目标平台的机器代码。因此，拼错宏名或把整数传给需要字符串的函数，通常在程序启动前就会被拒绝。编译成功只说明满足静态规则，并不保证业务计算正确；错误的计费公式仍可能顺利编译。

一个普通二进制程序以 `main` 作为用户代码入口。`fn` 声明函数，空圆括号表示没有参数，花括号界定函数体。函数写在文件前面或后面不决定执行顺序；`main` 中实际调用它的位置才决定何时进入该函数。库代码则不要求有 `main`，它通过公开的函数和类型供其他程序调用。
