### 4. 数值表示会影响业务结果

`f64` 使用二进制浮点表示，许多十进制小数不能精确存储，连续运算也可能累积舍入误差。金额常适合用整数记录最小单位，而不是直接比较浮点和是否严格相等。整数也不是无限精度：普通算术溢出的检查受编译配置影响，debug 构建通常会 panic，不能把这种差异当作业务规则；应按需求选择 checked、saturating 或 wrapping 系列操作。
<CourseCallout title="容易混淆的地方">

as 是显式转换但不等于范围检查。缩窄整数可能丢失高位；读取数组时下标必须有效，来自外部的数据优先用 get 检查。

</CourseCallout>
