### 1. 绑定、可变性与类型分别约束什么

`let` 为一个值建立名称绑定。默认不可变意味着初始化之后不能再次给该绑定赋值，并不意味着所有相关内存都永久只读。`let mut count: u32 = 0` 同时声明可重新赋值和固定的数值类型；之后可以赋另一个 `u32`，却不能赋字符串。Rust 的静态类型属于绑定及表达式，不会随运行时收到的数据自动改变。

初始化也可以晚一点发生，例如先声明 `let label;`，再在完整的 `if`/`else` 中分别初始化。编译器会分析每条控制流，要求读取之前一定完成初始化，同时防止不可变绑定被初始化多次。它不是给所有变量偷偷填入零或空值，所以“声明了就能读取”的习惯在这里不成立。
