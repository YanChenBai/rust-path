### 1. 推断是编译期求解，不是运行期猜测

整数有有符号与无符号之分，位宽决定取值范围；例如 `u8` 只能表示零到二百五十五，`i32` 可以表示正负整数。未受其他约束的整数字面量通常默认 `i32`，浮点字面量通常默认 `f64`。编译器会结合赋值、函数参数和返回值推断类型；遇到 parse 或空集合等存在多个答案的情况，需要用类型标注或泛型参数明确目标。

`usize` 适合表示集合长度和索引，其宽度随目标平台变化，并不保证总是六十四位。`bool` 只有两个值，不能用整数隐式替代。char 表示一个 Unicode 标量值，使用单引号；字符串用双引号，类型常为 `&str` 或 `String`。一个看起来完整的表情可能包含多个标量值，不能一律用单个 char 表示。
