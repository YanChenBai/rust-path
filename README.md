学习 Rust 时，读懂示例只是开始。Rust Path 把教材、代码编辑器、章节练习和专项项目放在同一个学习空间里，让你读完就能动手，用运行结果检查自己的理解。

目前包含 **32 章、76 个知识点、256 道章节题和 32 个专项项目**，从第一行 Rust 代码，逐步走到异步、网络与数据库。

## ✨ 在这里你可以

### 边读边运行，让概念变得具体

每个知识点从原理和对比示例开始，接着进入「亲手试一试」。修改输入、调整实现、观察结果，在同一页面完成阅读和实验。想继续深入时，可以展开对应的进阶讲解。

### 用练习检验理解

每章提供 8 道选择、填空或编程题，独立提交，即时反馈。编程题通过实际运行与断言检查结果；单题失败至少 3 次后，可以主动查看答案和解析。

本章题目全部通过后，会解锁一个专项项目，把分散的知识点组合起来，完成一个小作品。

### 拥有随手可用的 Rust 实验室

内置代码编辑器与终端，支持代码补全、悬浮说明和实时编译诊断，也可以执行运行、检查、构建和测试。

- 在 `main.rs` 与 `Cargo.toml` 标签间切换，按需选择课程支持的依赖。
- 调整编辑器与终端的上下、左右布局，拖拽分隔线分配空间。
- 进入网页全屏或折叠侧栏，集中阅读与编写代码。
- 隐藏示例里的 Rust 注释，先看实现，需要时再展开。
- 在终端中查看带颜色的运行输出，跟随程序执行观察结果。

> 网页默认使用浏览器模式。需要完整代码补全、悬浮说明、实时诊断或本机 Cargo 执行时，请前往[发布页](https://github.com/YanChenBai/rust-path/releases)下载适合当前系统的增强服务，按[学习指南](docs/learning.md#连接本机语言服务)启动并连接。本机需安装 Rust 工具链及 rust-analyzer、rust-src 组件。

### 把自己的理解留在教材旁边

每章都有共用的 Markdown 笔记，方便把不同课时的理解整理到一起。

阅读时还可以选中文字添加注释：原文会显示高亮，点击摘要即可展开内容；「本章注释」集中收纳所有标记，点击条目可以跨课时回到原文。

### 按自己的节奏继续学习

无需账号，草稿、答题记录、学习进度、笔记和布局自动保存在当前浏览器中。通过「学习足迹」导出或导入记录，备份学习成果，或在其他浏览器中继续。

清理站点数据会删除本地记录，导入会替换当前记录，建议定期导出备份。

## 🧭 学习路线

| 阶段         | 你将接触的内容                                                                      |
| ------------ | ----------------------------------------------------------------------------------- |
| 基础表达     | Rust 与 Cargo、变量与类型、函数与表达式、分支与循环                                 |
| 数据与所有权 | 移动与复制、借用与引用、切片与 UTF-8、结构体、枚举、集合                            |
| 可靠的抽象   | Option / Result、Trait、泛型、生命周期、闭包、迭代器、错误处理、模式匹配与 dyn 接口 |
| 工程实践     | 模块与可见性、测试与调试、文件 I/O、Cargo 与 Workspace、宏与属性                    |
| 资源与并发   | 智能指针、线程与消息、共享状态、Future / Tokio、取消与背压                          |
| 应用能力     | 序列化、CLI、日志、TCP / UDP、HTTP、SQLite 与事务                                   |

最后的完整示例会串联本机 HTTP 与文件数据库，并通过关闭连接后重新打开来验证数据持久化。

Unsafe / FFI、过程宏编写、性能分析与 WebAssembly 尚未列入当前课程。

## ✍️ 添加课程

可以补充现有课时，也可以添加完整章节。教材使用 Markdown 编写，Rust 示例独立维护，新增内容会自动进入课程目录。

1. 在 `src/docs/NN-name/` 编写章节、知识点、深入讲解、题目和专项项目。
2. 在 `course/NN-name/` 放置对应 Rust 示例、练习骨架与参考实现，在 Markdown 中引用源码。
3. 使用 `vp dev` 预览修改，完成后执行 `vpr verify:course` 验证教材和代码。

新增章节需要至少一个知识点、8 道章节题和一个专项项目。具体步骤、目录约定和示例见[教材编写指南](src/docs/README.md#添加内容的步骤)。
